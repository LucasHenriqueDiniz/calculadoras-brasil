# What the ANEEL tariff dataset and this site's two APIs hold

## ANEEL "Tarifas de Aplicação", resource `fcf2906c-7c32-4b9b-a637-054e7a5234f4`

Queried directly with `datastore_search`, the same endpoint `src/server/adapters/aneel.ts` uses, with
its B1 filters (`Tarifa de Aplicação`, `B1`, `Convencional`, `Residencial`, `Residencial`, `Não se
aplica`, `Não se aplica`, `MWh`).

**Fields per record:** `DatGeracaoConjuntoDados`, `DscREH` (the homologating resolution, e.g.
"RESOLUÇÃO HOMOLOGATÓRIA Nº 3.336, DE 18 DE JUNHO DE 2024"), `SigAgente`, `NumCNPJDistribuidora`,
`DatInicioVigencia`, `DatFimVigencia`, `DscBaseTarifaria`, `DscSubGrupo`, `DscModalidadeTarifaria`,
`DscClasse`, `DscSubClasse`, `DscDetalhe`, `NomPostoTarifario`, `DscUnidadeTerciaria`,
`SigAgenteAcessante`, `VlrTUSD`, `VlrTE`. The dataset was generated on 2026-11-14.

**B1 residential convencional, every period:** 1,927 records.

**COPEL-DIS row by row** (read the same day): 19 rows, but the rows starting 2025-06-24 and
2026-01-01 carry the same REH 3.472 and the same 366,67 + 275,75, so there are **18 distinct
periods**. No row covers 2012-06-24 → 2013-01-23 or 2016-06-24 → 2017-03-31. A history built from
this dataset has to merge the split and show the gaps. "Periods" in the table above counts rows, so it
overstates by one wherever the 2025 split occurs.

Each distributor's page can therefore carry its own 16-year series, the resolution behind each step,
and its rank among 103. The same dataset also holds the `Branca` modality by `NomPostoTarifario`
(not measured here), which is the input for "does the white tariff pay off at this distributor".

## This site's APIs, live

`GET /api/energy-tariffs?uf=PR` → `{available: true, source: "ANEEL", distributors: [103 items]}`. The
list is national, not filtered by state (PR returns "Âmbar Amazonas" first).

`GET /api/energy-tariffs?uf=PR&distributor=COPEL-DIS` → `tariffKwh 0.76802`, `tusd 0.45717`, `te
0.31085`, `taxesIncluded: false`, and the note "Não inclui impostos, bandeiras, contribuição de
iluminação pública nem particularidades da fatura."

`GET /api/fuel-prices?uf=SP&fuel=gasolina` → `averagePrice 6.36`, `minPrice 5.39`, `maxPrice 8.49`,
`sampleSize 1252`, `period "2026-11-08 a 2026-11-14"`, `isStale: false`. One week only: the adapter
reads the latest weekly summary workbook, not the historical series.

## How a data page would reach Google

`vite.config.ts` prerenders every path in `SEO_PAGES` at build time (`prerender.enabled`, no link
crawling). `/calculadora-custo-carro` gets its state table from `src/data/anp-weekly-snapshot.ts`,
generated by `scripts/refresh-anp-snapshot.mjs` and committed. A data page built the same way serves
its numbers in the HTML Googlebot fetches, and its freshness is the date of the last snapshot commit.
