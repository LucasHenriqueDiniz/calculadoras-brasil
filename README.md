# Calcule Brasil

A hub of Brazilian calculators for estimating day-to-day costs, taxes and common financial decisions in Brazil. The application uses React, TypeScript, TanStack Start and Cloudflare Workers.

The 49 public pages are prerendered at build time so that content, metadata and JSON-LD are delivered without depending on JavaScript execution. The calculators stay interactive after hydration.

The site's own content is written in Brazilian Portuguese, for a Brazilian audience. This repository — code, comments, docs and commit messages — is written in English.

**Contents:**

- 12 interactive calculators: car cost, living alone, electricity bill, subscriptions, pet, moving, IRPF 2026 (income tax), net salary, self-employed INSS, CLT vs PJ (employee vs contractor), supplementary pension and tax-free benefits.
- 15 blog articles with educational content and support for SEO clusters.
- 4 side-by-side comparisons: streaming, gym, moving and energy.
- 1 central comparison hub.
- 6 institutional pages: about, methodology, privacy, terms, contact and 404.

## Requirements

- Node.js 22.12 or newer
- pnpm (the exact version lives in the `packageManager` field of `package.json`)

## Development

```bash
pnpm install --frozen-lockfile
pnpm run dev
```

The local server starts at `http://localhost:8080`.

## Validation

```bash
pnpm run check
```

The gate runs:

- the types generated by Wrangler;
- the formula tests;
- TypeScript and ESLint;
- the client and Worker builds;
- prerendering of the 49 public routes;
- the SEO smoke test without JavaScript;
- the deploy dry-run;
- the dependency audit.

## Build and deploy

```bash
pnpm run build
pnpm run preview
pnpm run deploy:preview
pnpm run deploy
```

The build produces:

- `dist/client`: assets and prerendered HTML;
- `dist/server`: the TanStack Start Worker;
- `dist/client/sitemap.xml`: a sitemap generated from the central list in `src/lib/seo-pages.ts`.

The production target is Cloudflare Workers. The `preview` environment uses the `calcule-brasil-preview` Worker; production uses `calcule-brasil`.

`pnpm run preview` serves a local preview of the build for validation before deploying. The first remote deploy should go through `pnpm run deploy:preview`; use `pnpm run deploy` only after validating the preview Worker, the APIs, the sitemap, the 404 and the headers.

Deploys happen automatically through **Cloudflare Workers Builds**, connected to the repository: every push builds and publishes straight from Cloudflare. The commands above remain valid for a manual deploy from a local machine. GitHub Actions does not deploy — it only runs CI (typecheck, lint, tests and a build check).

## Variables and secrets

Non-sensitive variables live in `wrangler.jsonc`:

- `PUBLIC_SITE_URL`;
- `PUBLIC_DATA_CACHE_TTL_HOURS`.

Secrets must be configured through Wrangler or the Cloudflare dashboard, and never committed:

```bash
npx wrangler secret put DADOS_GOV_BR_TOKEN
```

## APIs

The public integrations are TanStack Start server routes:

- `GET /api/health`
- `GET /api/public-data/sources`
- `GET /api/fuel-prices?uf=RS&fuel=gasolina`
- `GET /api/energy-tariffs?uf=RS&distributor=...`
- `GET /api/vehicle-efficiency?brand=...&model=...`
- `GET /api/locations/states`
- `GET /api/locations/cities?uf=RS`

ANP and ANEEL have a timeout, a response-size limit, an edge cache and a manual fallback. Inmetro and the IBGE municipalities stay out of the current scope.

## SEO

- absolute canonical and Open Graph;
- `WebSite`, `Organization`, `WebApplication`, `BreadcrumbList` and `FAQPage` schemas;
- a sitemap generated during the build;
- `robots.txt` and `llms.txt`;
- a 1200×630 social image under 500 KB;
- visible institutional authorship and review date.

`FAQPage` is kept for semantic organisation and for consumption by AI systems, not as a promise of a Google rich result.

## Adding a calculator

1. Implement the pure formula in `src/lib/calculators/`.
2. Add the metadata to `src/data/calculators.ts`.
3. Create the route in `src/routes/`.
4. Include editorial content, a FAQ and structured data.
5. Register the URL in `src/lib/seo-pages.ts`.
6. Run `pnpm run check`.
